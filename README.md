# recipes
This is a beginner HTML recipes project.

In this project, a simple recipe website made of pure HTML and HTML basics is created and established for in depth understanding of the HTML basics and commands. 

## Opening the website
This website can be opened by following the steps below.
1. Clone the repository "https://github.com/O9SCARY/recipes.git" on github to your local machine.

2. Open the cloned repository in vscode or ny text editor

3. Run the html file (index.html) on localhost

4. The website opens and the recipes page displays.

NB: This page is pure HTML, No CSS styling or Javascript functionality added.
